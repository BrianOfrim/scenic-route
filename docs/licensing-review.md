# Licensing review for downloadable AI posters

Reviewed **2026-10-08** against commit `6283736df5be9a4d92a08bef0e84a427e915f89f`. This is a source and implementation review, not counsel clearance. A display license does not by itself establish permission to submit an image to an AI vendor. Public terms cannot establish the production account's contract, settings, or historical sample provenance.

## Actual product use

- `apps/api/src/tiles.ts` proxies OSM Standard, OpenTopoMap raster, and Esri World Imagery tiles. `MapView.tsx` displays OSM streets or Esri imagery. The schematic/no-basemap style is also available.
- `poster/grounding/snapshotTiles.ts` captures an off-screen WebGL canvas with attribution controls disabled. `PosterPanel.tsx` actually calls this with **satellite**; OSM/topo snapshot sources exist in the helper, but no current composer call selects them. Satellite capture happens while preparing references when the model supports at least three references, and during generation preparation. It is not confined to visible map browsing.
- OSM geometry from Overpass is rendered into schematic references. Generalized geography can use the bundled Natural Earth assets (`apps/api/assets/geography/README.md`). GPS-only references have a different source provenance.
- Satellite references can be masked, annotated with the route, and packed into contact sheets. References are uploaded and persisted; `apps/api/src/poster.ts` sends them through `createImage`, and reuses them for variants/refinement. `openrouter.ts` sends image URLs/data through OpenRouter. `.env.example` selects `meta/muse-image`; runtime configuration and the model picker can select other models.
- Generated images are stored and returned unchanged for individual download, sharing, and gallery ZIP export (`GalleryActionBar.tsx`, `RefineStudio.tsx`, `Gallery.tsx`). There is no deterministic attribution compositor or export notice here. An attribution prompt alone would not guarantee readable credits.
- Public assets include 52 Beltline theme examples plus thumbnails and three landing posters. `docs/theme-examples.md` identifies Muse Image for the theme collection, but the public manifest lacks input-source and generation records. The installer checks coverage and paths, not licensing provenance.

## OSM data and Standard tiles

**Confirmed:** OSM data is available under ODbL for reuse, with attribution and database obligations. The [copyright page](https://www.openstreetmap.org/copyright) requires credit and license access; printable images should include the copyright-page URL. [ODbL sections 4.3–4.6](https://opendatacommons.org/licenses/odbl/1-0/) distinguish Produced Works from publicly used Derivative Databases. Do not assume that every derived poster must be ODbL, or that extracting/distributing a derivative database is obligation-free.

The [OSMF attribution guidelines](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines) cover static images, interactive maps and artwork. They also discuss ML training; that example does not settle this reference-conditioned inference pipeline. Substantial OSM-derived posters should retain credit. A safe implementation target is readable `Map data © OpenStreetMap contributors — openstreetmap.org/copyright` on exports, with source provenance retained for variants and edits.

**Standard tile service implementation (2026-10-09; deployment pending):** The [Standard Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) independently requires visible attribution, application identification, accurate Referer handling and upstream-aware caching. The OSM-only proxy now identifies Scenic Route with a contact, forwards only an approved referring origin, persists tiles/cache metadata, respects HTTP freshness and validators, and conditionally revalidates expired tiles. A seven-day fallback applies only when explicit freshness is absent and response directives allow it; restrictive/invalid headers do not become fresh seven-day entries. Storage failures stop new upstream misses instead of bypassing the cache. Browser caching respects remaining freshness. Interactive OSM credits remain expanded and are positioned above mobile sheets; OSM Standard is rejected by the off-screen snapshot helper. No prefetch/offline feature is added. Production acceptance still requires the dedicated mounted Fly volume and the small-viewport/restart checks in the operations runbook. This is a service-compliance change, not clearance of OSM-derived poster exports, reference-conditioned inference, Esri, or OpenTopoMap.

**Remaining:** Confirm provider processing/retention permissions against ODbL and any applicable tile artwork rights, and determine whether public use of transformed geometry requires a derivative-database offer. Implement durable export attribution with source tracking, including old posters. This PR fixes the interactive street credit/link only; it does not claim pipeline compliance.

## OpenTopoMap

**Confirmed:** The project's [maintained repository](https://github.com/der-stefan/OpenTopoMap) identifies its online map as CC BY-SA and points to its [usage page](https://opentopomap.org/about#verwendung). The [project-hosted usage text](https://wiki.opentopomap.org/about) calls for visible OSM/SRTM data credit, OpenTopoMap cartography credit and CC BY-SA. Direct fetches of the usage site failed during review; the primary project repository remains accessible. The [maintained usage-page source](https://github.com/der-stefan/OpenTopoMap/blob/master/www/v1/about) is available for comparison. Do not conflate the online map with the separately noncommercial Garmin edition.

**Remaining:** The topo endpoint is available, but currently not selected by the composer. Before activating tile captures, confirm the exact served tile license/version and service conditions, preserve full attribution/license links, mark changes and resolve share-alike treatment of AI adaptations with the vendor. CC BY-SA permissions are conditional, not permission to strip credits or grant incompatible downstream rights. No provider change or new topo feature is made here.

## Esri World Imagery

**Confirmed:** The live [MapServer metadata](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer?f=pjson) and [World Imagery item metadata](https://www.arcgis.com/sharing/rest/content/items/10df2279f9684e4a9f6a7f08febac2a9?f=json) were fetched on the review date. The service-wide credit is Esri, Vantor, Earthstar Geographics, and the GIS User Community. Item terms reference Esri's agreement and state this layer is not intended for offline tile export. [Esri's MapLibre guidance](https://developers.arcgis.com/maplibre-gl-js/maps/raster-tile-basemaps/display-multiple-basemap-layers/) requires data-provider attribution. This PR replaces the bare Esri label with the current service-wide credit and item link. Extent-specific credits may still be necessary.

**Unresolved / launch decision required:** [Esri's Master Agreement](https://www.esri.com/content/dam/esrisites/en-us/media/legal/ma-translations/english.pdf), sections 3.2–3.4, conditions data representations, restricts scraping/storage, prohibits external AI/ML teaching/training, and incorporates third-party data terms. Inference conditioning must not be silently equated with training; neither is it established as permitted by these clauses. Identify the agreement and entitlement governing this anonymous legacy endpoint.

Esri's [published World Imagery AI extraction workflow](https://www.esri.com/arcgis-blog/products/arcgis-living-atlas/imagery/analyze-solar-adoption-in-arcgis-online-part2) uses exported inputs within ArcGIS and noncommercial derivatives within ArcGIS. That is a different workflow, not a grant for OpenRouter.

Ask Esri for written confirmation covering capture, masking, persistent reference storage, transfer to OpenRouter/Meta (including subprocessors and retention), AI inference, commercial downloadable posters, redistribution and required extent-specific attribution. Ask whether third-party imagery licensors impose additional limits. A successful unauthenticated tile response proves accessibility, not those rights. Do not launch this use on the strength of the display credit fix.

## Meta Muse Image and OpenRouter

**Confirmed:** The [Muse Image model listing](https://openrouter.ai/meta/muse-image) identifies image references and image output. [OpenRouter terms](https://openrouter.ai/terms), updated August 31, 2026, sections 5 and 6, require applicable model terms and sufficient input rights, pass obligations to customers, reserve output ownership to model terms and distinguish processing from optional logging/training. An API payment grants no rights to third-party map inputs.

The [Meta Model API terms](https://dev.meta.ai/legal/terms-of-service), updated October 2, 2026, expressly contemplate commercial integrations and outputs, recognize user input/output rights as between the parties to the extent law permits, require necessary input rights and downstream compliance, and address hosted platforms in Exhibit C. They distinguish Standard processing from Discounted training use. Exhibit C instead states that hosted-platform content stays with that platform and excludes Discounted terms; establish whether that exhibit applies to this endpoint before making a retention claim. The [AUP](https://dev.meta.ai/legal/acceptable-use-policy) prohibits removing provenance signals and distributing outputs without preserving applied watermarks/labels/metadata; no trademark permission or blanket non-infringement clearance follows from an output ownership clause. The [designation/geographic policy](https://dev.meta.ai/legal/geographic-use-policy), updated September 18, 2026, identifies Muse Image as Standard, prohibits its availability to end users in India, and lists additional restricted territories. Confirm product eligibility/access controls before global availability.

**Remaining:** Record the exact terms/version, hosted-platform designation, model tier, retention/training settings and applicable geographic conditions for the actual OpenRouter endpoint/account. Confirm whether provenance marks/citations must survive download and refinements. Resolve customer terms/privacy flow-down. Review each alternate selectable model independently. No account settings were read or changed, and no inference call was made. The commercial output grant is conditional on these obligations and valid input rights; it cannot cure the Esri question.

## Fonts, icons and dependencies

**Fonts:** `apps/web/index.html` remotely loads Fraunces and IBM Plex Sans from Google Fonts; schematic/contact-sheet code uses Plex. The primary [Fraunces OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/fraunces/OFL.txt) and [Plex OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsans/OFL.txt) permit embedding and commercial use subject to font-license conditions. Font copyright/license notices accompany redistributed font software; OFL does not impose its license on documents rendered with the fonts. If self-hosting, retain both notices and respect reserved names (Plex). Named prompt typography such as Helvetica does not show that a licensed font binary was embedded; don't claim a Helvetica software license from that prompt.

**Icons/marks:** No icon package is declared. Gallery/control icons are inline SVG paths; their presence alone does not establish authorship. The SR monogram has a design README and SVG source, but no creator-rights record. Google's colored G is embedded in `SignIn.tsx`; [Google's branding guidelines](https://developers.google.com/identity/branding-guidelines) govern its sign-in usage. Verify current button dimensions/padding and asset provenance; no endorsement or broader Google mark permission is inferred.

**Dependency inventory:** `prelaunch-evidence/licensing-dependencies.json` records all 277 locked registry package entries and license metadata, including dev/optional entries, not 277 deployed components. No entry lacks metadata. React/React DOM/fflate and most API dependencies declare MIT; MapLibre GL declares BSD-3-Clause; AWS SDK/sharp declare Apache-2.0; dotenv BSD-2-Clause. Metadata is evidence of declarations, not a complete binary/notice audit. [MapLibre's license](https://github.com/maplibre/maplibre-gl-js/blob/main/LICENSE.txt) includes bundled third-party notices; browser redistribution must preserve applicable notices. No complete browser third-party notice artifact exists in this tree. Verify the built bundle and add a corresponding notice artifact before distribution rather than claiming package metadata alone satisfies notice obligations.

**Exceptions requiring action:** Garmin FIT SDK 21.214.0 uses [its own license](https://github.com/garmin/fit-javascript-sdk/blob/main/LICENSE.txt), not MIT. Sections 1–2 grant limited internal business use and restrict third-party availability of technology/functionality; confirm the hosted customer import service with Garmin. [Sharp's licensing guidance](https://sharp.pixelplumbing.com/install/#licensing) covers Apache-2.0 and LGPL libvips binaries; distribution of container/native binaries requires the appropriate licenses/notices and source/relinking obligations. `caniuse-lite` declares CC BY 4.0 (build tooling). No legal conclusion is drawn from a lack of an npm warning.

The external MapLibre demo glyph URL in `MapView.tsx` is also a service/font dependency. Confirm the glyph font licenses and production service suitability if rendered text relies on it; no glyph asset rights are established by MapLibre's code license.

## Public themes and marketing assets

`styles.ts` references Paul Rand/Saul Bass, Mucha, Herbert Bayer, Tolkien/Middle-earth and NES/SNES; `themeExamples.json` exposes Middle-earth and Mucha spring identifiers/labels. These are style/palette instructions and public labels, not actual licenses to artwork, characters or trademarks. Do not infer permission from age, a historical style name, AI generation, or a supplied route name. Review output resemblance and possible affiliation claims, especially Tolkien-related material and game references, before public promotion. No theme is removed by this PR.

For the **52 theme originals + 52 thumbnails**, **three landing posters**, and **logo/favicons**, obtain a provenance ledger: creator/uploader authorization, generation date/model/provider terms, source route ownership, map/reference inputs, transformations, required credits and approved public uses. Repository records do not establish those facts for every asset. `docs/canadian-example-routes.md` includes candidate Parks Canada/OSM routes; that research does not establish which input generated the shipped posters. Don't attach speculative provider credits to every public sample.

**Natural Earth confirmed:** The bundled asset README/manifest identifies Natural Earth sources. Its [primary terms](https://www.naturalearthdata.com/about/terms-of-use/) put map data in the public domain, allow commercial modification/dissemination/printing and do not require credit. This permission applies to that data; it doesn't clear mixed OSM/Esri references, customer routes or generated artwork.
